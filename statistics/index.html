Statistics

Live database coverage statistics for the Nigerian Marine Biodiversity Reference Library. Coverage is computed dynamically from the data arrays — all stats update automatically when classifications change. Present requires West African records meeting the marker threshold (COI ≥5, 12S ≥3, 18S ≥1, 28S ≥1, rbcL ≥3) in both NCBI and BOLD/SILVA. Absent = zero WA records in both databases. Coverage reflects regional (West African) reference availability, not global sequence count.

Coverage classification methodology

The decision tree, marker thresholds, and database sources that underpin all statistics on this page are documented on the Database page. Classifications are computed dynamically at render time from the data arrays — no manual overrides.

Web statistics

Live visitor data requires a third-party analytics service. Since the site is now live, the recommended setup is GoatCounter — free for open-source projects, no cookies, GDPR-compliant, one script tag. Once installed, a public stats counter can be embedded here.

To enable live stats:
1. Create a free account at goatcounter.com (free for open-source / non-commercial sites)
2. Add your site — you'll receive a unique code (e.g. nmbl)
3. Add one line to assets/partials/footer.html:
<script data-goatcounter="https://YOUR-CODE.goatcounter.com/count" async src="//gc.zgo.at/count.js"></script> 4. Replace YOUR-CODE with your GoatCounter site code
5. Visitor counts and page views will appear in your GoatCounter dashboard and can be made public

Alternative: Google Analytics 4 (free, more detailed but requires a Google account and consent banner for EU visitors). GoatCounter requires neither.
