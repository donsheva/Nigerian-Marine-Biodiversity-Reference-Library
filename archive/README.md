# Archive — superseded material (not current data)

Everything in this folder is kept for the record only. **Figures in these files are out of date** and do not reflect the current classification on envirobiotics.org. For current data see `assets/js/data.js`; for the audit trail see `Data/v22/AUDIT.md`.

| Folder | Contents |
|---|---|
| `dashboards/` | Single-file dashboard versions v4–v19 (March 2026; v13 restored from repository history) and an earlier copy of the live dashboard. `_alt1` / `_alt2` are same-day variants saved with "(1)"/"(2)" suffixes. v20 is in `archive/`; v21, the canonical last single-file version, is at the repository root. |
| `old-site/` | The root redirect page used while v21 was live, and the original deployment guide. |
| `docs/` | Gap-report Word template and the nematode reference-library workflow diagram. |
| `misc/` | Placeholder files from the first scaffold. |

Related data moved from the curator's working folder on 14 November 2026:
- `Data/march-2026/` — query outputs from March 2026, the period of the analysis in Odedere & Rufai (2026), *Regional Studies in Marine Science* 103:105586. `nigeria_reflib_12S_placeholder.*` hold a single dummy sequence and are not data.
- `Data/v21/` — the April 2026 v21 re-verification run (log, report, patch, caches).
- `Data/v22.4/nmbl_v22_requery_cache.json` — raw NCBI/BOLD/SILVA/WoRMS responses behind v22–v22.4.
- `Scripts/legacy/` — earlier one-off scripts; `Scripts/reverify_v21.py`, `Scripts/nmbl_october_2026_verification.py`.

A personal email address in three scripts was replaced with the placeholder `your@email.com` (NCBI asks for a contact email when querying).
